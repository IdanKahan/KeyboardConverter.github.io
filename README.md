# KeyboardConverter.github.io 🗣️ Language Converter

This is a simple browser-based language converter that I made. It allows you to quickly switch between **Hebrew** and **English keyboard layouts** and see the result instantly.

---

## 🌍 What It Does

- Takes input text typed in the wrong keyboard layout (Hebrew or English).
- Converts it to the correct layout based on a key mapping.
- Supports live conversion as you type.
- Allows toggling between English ↔ Hebrew.
- Includes a **Copy** button to quickly copy the converted result.

---

## 🔧 How to Use

1. Open the HTML file in your browser.
2. Type or paste text into the **input** textarea.
3. Click the **Toggle Language** button to switch between Hebrew and English.
4. The converted text appears in the **output** textarea.
5. Click **Copy** to copy the converted result to your clipboard.

---

## 📝 Notes

- This tool does not translate words, it only converts the **keyboard layout**.
- Useful for when you accidentally type in the wrong language setting.

Feel free to customize the key mappings or UI to fit your needs!
